# 交付验收清单（CHECKLIST）

每篇论文交付前逐项打勾。任何一项不过 = 未完成。

## A. 英文版

- [ ] 编译零错误（log 中 `grep -E "^!"` 为空）
- [ ] 引用零警告（`grep -c "Warning: Citation"` == 0）
- [ ] PDF 页数合理（与 arXiv 官方 PDF 相差不超过 ±2 页）
- [ ] 保存为 `<英文标题>-en.pdf`

## B. 中文版

- [ ] 编译零错误
- [ ] 引用零警告 == 0
- [ ] 首页标题/摘要中文渲染正常（无豆腐块、无 Missing character）
- [ ] 保存为 `<中文标题>-zh.pdf`

## C. 翻译完整性

- [ ] `check_citations.py` 输出 ALL MATCH（\cite 键集合与顺序、\label/\ref 全一致）
- [ ] 章节标题全部中文化（`\section/\subsection/\paragraph` 扫描）
- [ ] 全部 `\caption` 图题/表题中文化
- [ ] 表头与行标签中文化（Method→方法、Ours→本文、average→平均、None→无……）
- [ ] PDF 全文 `pdftotext` 扫描无残留英文散文段落（图表内烘焙文字与参考文献除外）
- [ ] 术语一致：同一术语全文同一译法；首现括注英文
- [ ] 公式、实验数字、图表编号与原文一致（抽查 3 处）
- [ ] 算法环境注释已按约定处理

## D. 排版

- [ ] 渲染标题页 + 1 个密集正文页为 PNG 检查：无文字重叠、无溢出、公式表格完整
- [ ] 图像正常显示（非空白框、非占位符）
- [ ] 中英混排自然（ctex 自动处理；无手工塞空格）

## E. 打包交付

- [ ] `<英文标题>-en.pdf` 与 `<中文标题>-zh.pdf` 按标题命名
- [ ] `src-en/`：英文原始源码，构建产物已清理（aux/log/out/bbl*/blg/snm/toc）
- [ ] `src-zh/`：中文翻译源码，同样清理
- [ ] `说明.txt`：标题、编译引擎与完整命令、翻译约定、特别注意事项（禁 bibtex、
      插图转换、垫片、图内英文说明等）
- [ ] 引用完整性声明：说明.txt 注明"全部 \cite 与原文逐一对齐，参考文献保持英文"

## F. 多篇任务附加

- [ ] 每篇一个目录或一个 zip；总包附收录清单（总说明.txt）
- [ ] 交付目录内无中间产物（渲染 PNG、pkg stage、备份文件）
- [ ] 若有通知链路：完成消息已发出
